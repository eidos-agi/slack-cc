## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Reviews are a top-3 local pack ranking factor. Currently: 5 testimonials on about page, some Yelp reviews, no systematic process. A competitor asking every customer for a Google review accumulates 50+ reviews in 90 days.

Three parts:
1. **Review schema** — Add AggregateRating + Review JSON-LD to testimonials on about page
2. **Review request system** — Automated post-service email/SMS via HubSpot asking for Google review
3. **Review management** — Respond to all existing Yelp/Google reviews

Target: 50+ Google reviews in 90 days.

Counterfactual: A prospect choosing between two dumpster companies picks the one with 4.8 stars and 87 reviews over the one with 4 reviews.
