# SEO Plan — greenmarkwaste.com

*Created: 2026-02-20*
*Status: Planning*
*Target: Commercial waste hauling — North Texas + Indiana*

## Brand Focus
Greenmark Waste Solutions — B2B focus. Target keywords: commercial hauling, construction waste, roll-off dumpsters, compactors, industrial waste solutions.

## Phase 1: Foundation (Days 1-30)

### Audit & Baseline
- [ ] Run PageSpeed Insights on homepage + service pages (desktop + mobile)
- [ ] Screaming Frog crawl — broken links, missing metas, thin content
- [ ] Ahrefs/Semrush — current keyword rankings, domain authority, backlink profile
- [ ] Set up GA4 with conversion tracking (quote forms, tel: clicks)
- [ ] Set up Google Search Console, submit sitemap
- [ ] Record baseline: Core Web Vitals (LCP, INP, CLS), organic sessions, keyword positions

### Technical Fixes
- [ ] Implement `LocalBusiness` schema on homepage + contact page
- [ ] Implement `Service` schema on each service page (serviceType, areaServed)
- [ ] Optimize title tags: `[Service Keyword] in [City] | Greenmark Waste`
- [ ] Write compelling meta descriptions with CTA for each page
- [ ] Verify XML sitemap is dynamic and submitted to GSC
- [ ] Review robots.txt — not blocking critical resources
- [ ] Compress all images (truck photos, dumpster photos)
- [ ] Enable browser caching and Gzip compression

### Google Business Profile
- [ ] Complete every field on all listings
- [ ] List every service explicitly (e.g., "20-yard dumpster rental")
- [ ] Add dumpsters as "Products" with photos + quote link
- [ ] Upload photos: trucks, dumpsters at job sites, staff, office
- [ ] Populate Q&A section proactively
