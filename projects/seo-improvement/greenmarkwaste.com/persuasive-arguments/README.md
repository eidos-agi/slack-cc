# The Case for Website Modernization: AI Moved the Goalposts

This folder contains the evidence, data, and reasoning that support replacing the Webflow site with an Astro build, centralizing domain/hosting accounts, and adding Cloudflare as a DNS layer.

**The core argument:** When the Webflow site was built, it was a good choice. Two things changed — Google got stricter about mobile speed, and AI tools made it possible to build a faster site without an agency. Nobody made a bad decision; the game changed, and now we can do better for less.

**Audience:** Michael Nguyen (CEO), Alex Kaye (CFO), Lannis Nicholson (CRO), investors, and anyone who asks "why are we doing this?"
