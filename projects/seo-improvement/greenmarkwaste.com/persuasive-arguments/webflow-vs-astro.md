# Webflow vs. Astro: How AI Moved the Goalposts

When the Webflow site was built, it was a solid choice — good design, quick to launch, no developers needed. Two things changed: Google raised the bar on mobile speed (it's now a direct ranking penalty), and AI tools made it possible to build and maintain a high-performance site without an agency. This comparison shows where the landscape shifted.

## Performance

| Metric | Webflow | Astro on Railway | Winner |
|--------|---------|-----------------|--------|
| Mobile speed score | 47/100 (Poor) | 92/100 (Good) | **Astro** |
| Desktop speed score | ~70/100 | 99/100 | **Astro** |
| Largest Contentful Paint | 17.5 seconds | 2.7 seconds | **Astro** (6.5x faster) |
| Cumulative Layout Shift | Unknown (high) | 0.001 | **Astro** |
| Total Blocking Time | Unknown | 0 ms | **Astro** |
| Google ranking impact | Penalized | Rewarded | **Astro** |

## Cost

| Item | Webflow | Astro on Railway | Winner |
|------|---------|-----------------|--------|
| Hosting | $14–$39/month per site | $0 incremental | **Astro** |
| SSL certificate | Included | Included (Railway/Cloudflare) | Tie |
| CDN | Included (Webflow's CDN) | Free (Cloudflare) | Tie |
| Domain (GoDaddy) | ~$20–$40/year | ~$20–$40/year | Tie |
| Designer/agency | Unknown (ongoing contract?) | $0 (team + AI tools) | **Astro** |

## Control

| Factor | Webflow | Astro | Winner |
|--------|---------|-------|--------|
| HTML output | Generated by Webflow — can't customize | Full control — every tag, every attribute | **Astro** |
| CSS | Webflow's CSS framework | Tailwind CSS — full control | **Astro** |
| JavaScript | Webflow loads its own JS files | Zero JS by default — add only what's needed | **Astro** |
| SEO markup | Limited — hard to add custom schema | Full JSON-LD, OpenGraph, structured data | **Astro** |
| Image optimization | Webflow's automatic processing | Full control — format, size, lazy loading | **Astro** |
| URL structure | Webflow's routing | Full control | **Astro** |

## Editing & Maintenance

| Factor | Webflow | Astro | Notes |
|--------|---------|-------|-------|
| Who can edit | Anyone with Webflow editor access | Daniel + AI tools (Claude) | Astro requires code; Webflow has drag-and-drop |
| Learning curve | Low (visual editor) | Higher (code-based) | Not relevant — Daniel and AI handle it |
| Edit → live speed | Instant (Webflow publish) | ~2 minutes (commit → Railway deploy) | Both are fast enough |
| Content migration | Trapped in Webflow CMS | Export to any format | **Astro** — no lock-in |
| Templating | Webflow's CMS collections | Astro components — reusable, composable | **Astro** |

## Vendor Lock-In

| Factor | Webflow | Astro | Winner |
|--------|---------|-------|--------|
| Content portability | Trapped in Webflow's CMS — export is limited | Standard HTML/CSS/JS files — works anywhere | **Astro** |
| Hosting portability | Must host on Webflow (or export limited HTML) | Deploy to any hosting provider | **Astro** |
| What happens if vendor disappears | Site goes down, content hard to recover | Site keeps running — static files don't need Astro to exist | **Astro** |
| Can switch frameworks later | Must rebuild from scratch | Can switch to Next.js, Hugo, etc. — same content | **Astro** |

## SEO & AI Readiness

| Factor | Webflow | Astro | Winner |
|--------|---------|-------|--------|
| Google Core Web Vitals | Fails mobile thresholds | Passes all thresholds | **Astro** |
| Structured data (JSON-LD) | Hard to customize | Full control | **Astro** |
| Semantic HTML | Webflow adds wrapper divs | Clean, semantic output | **Astro** |
| Service-area pages | Manual creation (editor effort per page) | Templated (generate 30+ city pages from data) | **Astro** |
| Blog/content | Webflow CMS (locked in) | Markdown files + any headless CMS | **Astro** |
| AI search optimization | Limited by generated HTML | Full control over structure | **Astro** |

## When Webflow Still Wins

To be fair, Webflow has real strengths:
- **Visual editing** — Non-technical people can make changes with drag-and-drop
- **Design speed** — A designer can create pages quickly in the visual editor
- **Built-in CMS** — Content management without code

These are genuine advantages — and they're why Webflow was a good choice when the site was built.

**What changed:** AI tools now provide these same benefits without the platform lock-in:
- AI can build and modify pages faster than a Webflow editor
- A headless CMS (Decap, Tina — both free) can be added for non-technical self-service editing
- The speed and SEO trade-offs that Webflow imposes are no longer acceptable given Google's stricter mobile requirements

## The Self-Service Path

One valid concern: "If we leave Webflow, can non-technical people still update the site?"

Yes. The Astro architecture supports adding a headless CMS that gives editors a browser-based interface for content changes — headings, text, images, blog posts — without touching code. This can be set up when Greenmark is ready for it, either during or after the migration. Nobody should be permanently locked into needing a specific person or agency to update their own website.

## Summary

Astro wins on **performance, cost, control, SEO, AI readiness, and vendor independence**. Webflow's historical advantage (visual editing) is now available through headless CMS tools that don't carry Webflow's speed and lock-in penalties.

The Webflow site served Greenmark well. AI moved the goalposts — and now a better option exists.
